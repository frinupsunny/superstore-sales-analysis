# Superstore Sales Analysis Dashboard

## Project Overview
This project analyzes Superstore sales data using MySQL and Power BI. It provides insights into sales, profit, customer, product and regional performance.

## Technologies Used
- MySQL
- SQL
- Microsoft Power BI

## Dataset
The cleaned dataset contains 9,994 records and 28 columns.

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Quantity
- Total Customers

## Dashboard Features
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Profit by Category
- Interactive filters for Year, Region, Category and Segment

## Project Files
- sales_analysis_dashboard.pbix – Power BI dashboard
- superstore_clean.csv – Cleaned dataset
- sales_analysis.sql – SQL analysis queries

## Learning Outcomes
- MySQL database management
- SQL queries and data analysis
- MySQL and Power BI integration
- Interactive dashboard development
